# Fuga nell'Eixample

Un gioco 2D visto dall'alto sulle vere strade dell'Eixample di Barcellona.
Guida Kiko, raccogli le tessere di trencadís e scappa dai piccioni. I churros sui luoghi famosi ti fanno scacciare i piccioni.

**Comandi:** frecce o WASD per muoverti, rotella o +/− per lo zoom, P per la pausa, V per cambiare vista (foto aerea o notte).
Su telefono: scorri col dito o usa i tasti a schermo, due dita per lo zoom.
